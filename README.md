# 月饼和小熊猫的英语小屋

红棕色长尾小熊猫陪月饼学习英语。12周60节课、96个核心词、预制中英文语音、原创矢量插画与轻量动画。首次联网下载，之后可以离线学习。

当前课程版本为2.0.1，共1527段引用预制语音，完整离线资源约40.2MB。

GitHub仓库：https://github.com/npiczhen/yuebing-english

网页发布地址：https://npiczhen.github.io/yuebing-english/ （首次部署完成后可访问）

## 家长第一次使用

1. 在安卓平板浏览器打开发布网址，进入「家长入口」。
2. 查看实际下载大小，点击「下载完整12周课程」，保持页面打开。
3. 等待显示「12周课程已可离线使用」。中断后再次点击下载，会检查并补齐缺失的文件。
4. 在浏览器菜单选择「安装应用」或「添加到主屏幕」。不同浏览器名称可能不同。
5. 关闭页面，打开飞行模式，再从桌面图标打开，试播一个单词。首次缓存之前不能离线使用。

如果浏览器不支持安装，可在同一浏览器保存书签打开；离线能力需以「检查离线完整性」和实际断网重开测试为准。清理浏览器数据、换浏览器或换设备后需要重新下载。

## 每天怎么玩

点击「开始今天的小冒险」或「继续我们的故事」，按6个环节进行：打招呼、听新词、看故事、找一找、说一说、一起玩。全部英文和操作提示都可点播放。故事可暂停、逐幕播放或自动播放；每次都可以重听。

15分钟是建议活动节奏，可以暂停、提前结束、跳过跟说或重玩。最后两分钟，请家长陪月饼抱着家里的小熊猫玩偶完成生活任务。“说一说”支持本机跟读录音和回放，不自动判断发音。

打招呼图片、新词、字母示范、故事和跟说均对应本课词汇，例如Day 02为bird、fish，字母示范为B—bird、F—fish。听音游戏先练本课词汇，再明确提示「复习以前学过的词」；选项只使用截至本课学过的词。12类提示语各有3—5种说法，随机选择时避开最近两条，同一环节点重播保持当前说法。

进度只保存在当前浏览器。完成课程后获得贴纸；不会因漏学一天而失去贴纸。家长页面可导出和导入 JSON 进度备份，导入会询问是否替换当前进度。

## 和小熊猫玩一下，歇一会儿

“听新词/听熟词”里新增6组中文互动小邀请，每组有两种配图选择和对应中文回复。可以挥手、抱玩偶、模仿小鸟小鱼，也可以选择先听或轮流说。选择轮流说后，小熊猫会接着播放本课英文示范；这些互动都可以跳过。

各环节都有“休息一会”，听音游戏答到第三题后也会出现休息邀请。休息时暂停计时、关闭麦克风，继续时保留故事画面和已答进度，没有倒计时或强制练习。

第11周加入one—eight数量任务，第12周加入感受、需求、大小和快慢。原来重复的教学目标已调整；故事仍回忆以前的动物、玩具与物品。

## 听听自己的声音

在“说一说”先点“听小熊猫示范”，再点“开始录音”。首次由家长在浏览器提示中允许麦克风。说完点“停止录音”，然后点“听听我的声音”；还想试就点“再录一次”。每次最多20秒，切换词语、离开课程或进入后台都会关闭麦克风。

录音只保存在当前浏览器，不发送到服务器、不做发音评分。每个课程跟读项目保留最近一次，最多保存80段；超过后替换最早的。可以删除当前录音，家长入口可以删除本机全部录音。录音不包含在JSON进度备份中，清理浏览器数据会丢失录音。存储失败时会提示，并允许当次回放；没有麦克风权限也可以继续听示范、学习课程。

中文提示采用微软“晓晓”神经语音，预先生成MP3缓存，语速降低8%。制作时向微软发送课程台词；儿童的跟读录音不进入语音制作流程。英文仍为Kokoro af_heart美式示范，制作与播放流程见 scripts/audio-README.md。所有语音是合成配音。

## 离线下载和更新

- 页面、课件、图片、提示和全部音频均由同一个网址提供，不依赖外部播放器或在线语音API。
- 下载按资源检查 SHA-256 与字节数，全部成功后才切换可用课程版本。
- 下载失败或暂停会保留已下载资源；新版本失败时继续使用旧的完整版本。旧包中未变化的资源通过逐项SHA验证后复用，只联网补齐新增或变化内容。
- 如离线资源缺失，请联网，在家长入口点「检查并修复下载」。
- 更新由家长点击「检查新版本」后主动下载。学习中不强制刷新。
- 下载完成后点“打开已下载的12周课程”，立即载入新课；保留原有学习进度和录音。
- 若旧页面仍只有4周或8周，直接打开 [独立更新入口](https://npiczhen.github.io/yuebing-english/update.html?yb-update=repair)，点“下载并打开12周升级版”，完成后自动打开课程列表。该入口绕过旧页面和旧下载清单，无需清除浏览器数据。
- 若旧版本提示「资源校验未通过：./index.html」，在同一页面点击「检查新版本」，再点击下载即可；不需要清除浏览器数据或学习进度。离线首页已改为校验后的固定数据封装，避免托管服务临时插入脚本导致误判。
- 首次使用与更新需要互联网；日常离线使用不需要电脑开机。缓存并非永久备份，系统存储清理可能删除内容。

## 源码和本地预览

`dist/` 是可直接部署的静态网站；没有运行时依赖、服务器数据库或API密钥。

```powershell
node scripts/serve.mjs
```

电脑上打开 `http://localhost:4173`。本地文件的 `file://` 打开方式不支持 Service Worker，因此不要把直接双击 HTML 当作平板安装方式。正式部署需 HTTPS。

```powershell
node scripts/content.mjs
node scripts/manifest.mjs
node scripts/check.mjs
node --test tests/*.test.mjs
```

修改内容脚本后会重建课程数据和音频清单，应重新生成新增或变化的音频，再生成资源清单。课程编号保持稳定，旧进度可以沿用。制作音频的模型和依赖仅保存在忽略的 `.audio-tools/`，不会发布到网页；音频生成脚本和报告在工程中保留。

`scripts/browser-qa.mjs` 使用本机已安装的 Playwright 与 Chromium，包含桌面/平板截图和完整离线验收，可通过环境变量 `YB_TEST_URL` 指定预览网址。运行前调整脚本中的本机浏览器路径。

`scripts/lesson-content-qa.mjs` 逐课核对60节课的图片、字母与单词、故事句子，验证Day 02实际音频请求、提示语随机选择和旧词复习标记。`scripts/offline-entry-regression.mjs` 以原始部署提交复现首页校验故障，验证旧缓存升级；该专项脚本需要保留工程Git历史。`scripts/recording-qa.mjs --full` 验证录音/回放、权限拒绝、延迟授权取消、存储失败保护、80段上限及20秒自动停止；使用Chromium测试麦克风，不替代真实平板验收。

## 免费静态部署

本版本使用GitHub Pages。仓库Settings → Pages中将Source设为GitHub Actions；提交main后自动校验并发布dist。所有资源使用相对路径，兼容仓库子路径。发布及旧网址进度迁移见[GitHub Pages说明](docs/GitHub-Pages发布.md)。新域名首次需要重新下载课程，旧录音继续保存在旧网址的浏览器数据中。

发布网址公开可访问，课程中仅含昵称和学习内容。学习记录不上传；没有账户管理、自动同步或统计追踪。

课程表见「课程表与12周路线.md」。12周课程已全部制作完成；第9—10周学习位置和天气，第11—12周学习数量、感受与对比；全部课程包含六幕互动故事。安卓真机、实际家庭网络与真人逐条听审的完成情况，以交付说明为准。

`scripts/upgrade-flow-qa.mjs` 使用真实1.2.1八周缓存验证独立入口升级到12周60课，保留进度和录音。测试会拒绝重复下载未变化的旧音频，确认复用正确，并破坏一段缓存音频验证SHA检查后重新下载。可用YB_LEGACY_COMMIT选择更早版本。

`scripts/adventure-qa.mjs --all` 验证自动三遍朗读、60个六幕故事、120次任务、休息续玩及录音；旧的final-weeks-qa为1.3版历史专项脚本，其熟词声音游戏断言不适用于2.0。

## 六幕互动升级

前4周主题、顺序、词汇和原英文核心台词保留；60课故事均按六幕展开，第3、5幕需要月饼操作。听词环节自动三遍+一句，卡片跟随实际发声高亮。找一找保留听音选图并增加送物、位置、颜色和数量任务。完整逐课路线见课程表，修改分类见 docs/课程修改清单.md。

新版进度继续使用原本机存储键，兼容旧进度导入；旧录音可在家长入口回放。后两周新目标使用独立完成记录，不删除旧贴纸。首次联网更新完成后离线学习，切换版本前逐条SHA校验；更新失败保留旧版。
